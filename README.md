# Calculadora con sistema de seguridad y alarma en Python

# Descripción

Proyecto desarrollado en Python que combina una calculadora básica con un sistema de seguridad mediante contraseña.

La aplicación solicita una contraseña antes de permitir el acceso. Si el usuario introduce la contraseña incorrecta dos veces, se activa una alarma como medida de seguridad.

# Objetivo del proyecto

Aplicar conceptos de programación mediante la creación de una aplicación que integre:

* Lógica de programación.
* Validación de datos.
* Condicionales y ciclos.
* Manejo de entradas del usuario.
* Reproducción de sonidos mediante Python.

# Tecnologías utilizadas

* Python
* PyGame (para la función de alarma)
* Entorno de desarrollo Python

# Funcionalidades

Acceso protegido…
Control de intentos fallidos.
Activación de alarma después de dos intentos incorrectos.
Operaciones matemáticas básicas de una calculadora.
