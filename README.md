# Calculadora con sistema de seguridad, límite de operación y alarma en Python

# Descripción

Proyecto desarrollado en Python que integra una calculadora con un sistema de seguridad mediante contraseña y control de límites de operación.

La aplicación solicita una contraseña para acceder. Después de dos intentos incorrectos, activa una alarma como medida de seguridad.

Además, el programa supervisa los resultados de los cálculos. Si la operación supera el límite establecido, activa una señal de alerta mediante una luz roja.

# Objetivo del proyecto

Aplicar conceptos de programación para desarrollar una solución que integre:

* Validación de contraseña.
* Control de intentos.
* Manejo de límites y condiciones.
* Operaciones matemáticas.
* Sistema de alertas.

# Tecnologías utilizadas

* Python
* PyGame (alarma y elementos multimedia)
* Lógica de programación

# Funcionalidades

✅ Calculadora de operaciones básicas.
✅ Acceso protegido con contraseña.
✅ Alarma después de dos intentos fallidos.
✅ Detección de valores que superan un límite establecido.
✅ Activación de luz roja como señal de alerta.

# Aprendizajes

Este proyecto permitió desarrollar conocimientos en programación, estructuras condicionales, control de flujo, validación de datos e integración de elementos de alerta en una aplicación.
